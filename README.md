# 📦 Inventa

Sistema de gestión de inventario full-stack.

- **Frontend**: React + Vite — `/frontend`
- **Backend**: Spring Boot + Hibernate + MySQL — `/backend`

## Inicio rápido

```bash
# Backend (terminal 1)
cd backend
# Editar src/main/resources/application.properties con tu password MySQL
mvn spring-boot:run

# Frontend (terminal 2)
cd frontend
npm install
npm run dev
```

Abre http://localhost:3000 → usuario: `admin` / contraseña: `admin123`

Ver README dentro de cada carpeta para instrucciones detalladas.
